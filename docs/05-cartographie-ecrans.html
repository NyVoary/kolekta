Architecture de l'information — v1

Kolekta

Pour chaque écran : ses éléments, l'action derrière chacun, la story qui la justifie et l'endpoint API appelé. Règle : un bouton sans story est soit inutile, soit le signe qu'une story manque. Une seule application Vue : routes publiques et client sous /, équipe sous /admin.
